# 프로젝트 자료

| 경로 | 용도 |
|---|---|
| `app_seed/` | 최초 등록 자료·청구 상세와 초기 위험도 자료 |
| `billing/` | 재사용하는 정제 청구 이력과 검토된 계량기 매핑 |
| `processed/` | 현재 앱·모델이 재사용하는 과거 정제 관측·청구·승하차·달력 자료 |
| `ml_dataset/` | 기존 학습·검증·평가 분할 자료 |
| `raw/` | 남겨 둔 원자료 입력·검토 자료 위치 |
| `runtime/` | 운영 DB·수집 원본·갱신한 자료·모델 결과·스냅샷의 기본 저장소 |

새 수집 결과는 `APP_DATA_DIR` 아래에 저장합니다. 기본값은 `data/runtime/`이며 사용자·세션·계량기 자료를 포함하므로 비공개로 유지합니다.

운영에 사용하지 않는 이전 원자료·통계·실험 결과는 [`archive/`](../archive/README.md)로 옮겼습니다. `archive/data/`는 이전 경로 구조를 보존합니다. 현재 코드의 초기 위험도 입력은 `app_seed/risk/test_anomalies.csv`입니다.
