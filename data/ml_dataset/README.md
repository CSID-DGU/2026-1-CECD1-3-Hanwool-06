# 데이터셋 설명

서울 지하철 역별 일별 승하차 인원 및 상수도 사용량 데이터셋입니다.

아래 표는 보존한 기존 학습 자료의 범위입니다. 이 폴더는 현재 모델의 기본 입력으로 유지합니다. 운영 갱신 명령 `python -m back.pipelines.refresh`는 새 분할 자료를 `APP_DATA_DIR/dataset/`에 생성하며 기본 경로는 `data/runtime/dataset/`입니다. 이전 실험 결과는 [`archive/`](../../archive/README.md)에 보관합니다.

---

## 파일 구성

| 파일 | 기간 | 행 수 | 설명 |
|---|---|---|---|
| `master.csv` | 2022-01-02 ~ 2026-04-30 | 65,856 | 전체 데이터 (참조용) |
| `train.csv` | 2022-01-02 ~ 2025-06-24 | 44,731 | 학습용 |
| `valid.csv` | 2025-06-25 ~ 2025-11-30 | 10,872 | 검증용 |
| `test.csv` | 2025-12-01 ~ 2026-04-30 | 10,253 | 평가용 |

> train / valid / test는 master.csv를 시간 순으로 분할한 것입니다.

---

## 분할 기준

**시간 순 분할 (temporal split)**

랜덤 분할 시 미래 데이터가 학습에 섞이는 데이터 누수가 발생하므로, 날짜 기준으로 순서대로 분할했습니다.

- 분할일은 아래 보존 파일의 날짜 경계를 그대로 사용합니다. 새 수집 자료는 평가 구간 뒤에 이어 붙입니다.
- 행 비율: 67.9% : 16.5% : 15.6% (역마다 데이터가 있는 날짜 수가 달라 차이 있음)

## 컬럼 설명

| 컬럼 | 설명 |
|---|---|
| `고객번호` | 아리수 고객 식별 번호 |
| `사업소명` | 관할 수도사업소 |
| `고지서_성명` | 아리수 청구서 표기 역명 |
| `역명` | 정규화된 역명 (호선 포함, 예: 건대입구역7) |
| `날짜` | YYYY-MM-DD |
| `승차총승객수` | 당일 승차 인원 |
| `하차총승객수` | 당일 하차 인원 |
| `총승객수` | 당일 승차 + 하차 인원 |
| `일사용량_톤` | 당일 상수도 사용량 **(예측 타겟)** |
| `일유형` | 평일 / 주말 / 공휴일 (대체공휴일 포함) |
| `요일` | 월 / 화 / 수 / 목 / 금 / 토 / 일 |
