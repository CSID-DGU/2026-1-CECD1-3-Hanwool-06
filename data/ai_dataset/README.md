# 데이터셋 설명

서울 지하철 역별 일별 승하차 인원 및 상수도 사용량 데이터셋입니다.

---

## 파일 구성

| 파일 | 기간 | 행 수 | 설명 |
|---|---|---|---|
| `master.csv` | 2022-01-02 ~ 2026-05-08 | 69,903 | 전체 데이터 (참조용) |
| `train.csv` | 2022-01-02 ~ 2025-06-24 | 47,292 | 학습용 |
| `valid.csv` | 2025-06-25 ~ 2025-11-30 | 11,686 | 검증용 |
| `test.csv` | 2025-12-01 ~ 2026-05-08 | 10,925 | 평가용 |

> train / valid / test는 master.csv를 시간 순으로 분할한 것입니다.

---

## 분할 기준

**시간 순 분할 (temporal split)**

랜덤 분할 시 미래 데이터가 학습에 섞이는 데이터 누수가 발생하므로, 날짜 기준으로 순서대로 분할했습니다.

- 날짜 기준 비율: **8 : 1 : 1**
- 행 비율: 67.6% : 16.7% : 15.7% (역마다 데이터가 있는 날짜 수가 달라 차이 있음)

## 컬럼 설명

| 컬럼 | 설명 |
|---|---|
| `고객번호` | 아리수 고객 식별 번호 |
| `사업소명` | 관할 수도사업소 |
| `고지서_성명` | 아리수 청구서 표기 역명 |
| `역명` | 정규화된 역명 (호선 포함, 예: 건대입구역7) |
| `날짜` | YYYY-MM-DD |
| `승차총승객수` | 당일 승차 인원 |
| `하차총승객수` | 당일 하차 인원 |
| `총승객수` | 당일 승차 + 하차 인원 |
| `일사용량_톤` | 당일 상수도 사용량 **(예측 타겟)** |
| `일유형` | 평일 / 주말 / 공휴일 (대체공휴일 포함) |
| `요일` | 월 / 화 / 수 / 목 / 금 / 토 / 일 |
